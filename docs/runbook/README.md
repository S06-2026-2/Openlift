# Runbook

Como operar o OpenLift na prática: subir, resetar, diagnosticar e preparar a demo. Escrito para quem está com o terminal aberto e algo não funcionou.

| Documento | Quando usar |
|---|---|
| [`subir-ambiente.md`](subir-ambiente.md) | Primeira vez no projeto, ou o ambiente parou de funcionar |
| [`problemas-comuns.md`](problemas-comuns.md) | Mensagem de erro conhecida (Windows, Docker, Flutter, banco) |
| [`checklist-demo.md`](checklist-demo.md) | Véspera e dia de demo |

**Ainda não existem** (entram quando a funcionalidade existir):

- **Operar o relay próprio** — `strfry` no compose (RF-60, Sprint 4).

Para rotas, testes e variáveis do backend, veja também [`api/README.md`](../../api/README.md).
