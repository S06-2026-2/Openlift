## Como fazer

1. **Antes da reunião**, alguém preenche a seção **Fatos** a partir do board e do repositório: o que foi entregue, o que ficou, números. Fato é o que dá para conferir num link.
2. **Na reunião** (até 30 min, dentro da reunião de segunda), cada pessoa traz um ponto para cada pergunta: o que foi bem, o que atrapalhou, o que mudar.
3. **Ações** saem com **dono e prazo**. Ação sem dono não acontece. Na retro seguinte, a primeira coisa é conferir as ações da anterior.
4. A ata entra por PR (`docs/retros-sprint-N`), como qualquer documento.

Modelo em [`modelo.md`](modelo.md).

**Regra de ouro do projeto:** se alguém estourou as 6 h semanais com frequência, o problema é o escopo, não a pessoa. Isso é assunto de retro, e a ação é cortar escopo ([`CONTEXTO.md` §2](../CONTEXTO.md#regra-de-ouro)).
