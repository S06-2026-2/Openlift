# Wireframes — Sprint 1

Wireframes de baixa fidelidade das 5 telas núcleo do OpenLift (Login, Dashboard, Novo Treino, Feed Social, Perfil), feitos pra alinhar o time antes da implementação real a partir do Sprint 2 — ver `implementation.md` na raiz do repo.

**Ver/editar:** [OpenLift Wireframes Sprint 1](https://claude.ai/code/artifact/c7884706-27b6-4ee2-894c-95cf89851ffe) (canvas publicado — cada tela é editável direto ali: arrastar, trocar texto/cor, etc.)

## Arquivos

- `Login.dc.html`, `Main.dc.html` (Dashboard), `NovoTreino.dc.html`, `Feed.dc.html`, `Perfil.dc.html` — uma tela cada
- `BottomNav.dc.html` — componente de navegação inferior, reaproveitado nas 4 telas autenticadas
- `canvas.json` — layout (posição de cada tela no canvas)

Esses arquivos são o formato "Design Component" do Claude Design, não HTML comum — servem como fonte/histórico do que foi publicado. Pra editar de verdade, use o link acima.
